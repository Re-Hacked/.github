## 👋 About

Re-Hacked LSH is a small research group focused on cybersecurity and understanding how software works.

We explore topics like reverse engineering, system internals, and security research while sharing what we learn.

Re-Hacked LSH is a subgroup of **TakımÇizgisi LSH Community**.
